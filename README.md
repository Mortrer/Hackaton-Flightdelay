# ✈️ FlightOnTime - Backend: Data Validation & API Standards

## 🚀 Mi Rol en el Equipo
Durante este Hackathon, colaboré en un equipo multidisciplinario enfocado en la predictibilidad de vuelos mediante Machine Learning. Dado que la precisión del modelo depende directamente de la calidad de los datos, mi responsabilidad principal fue **asegurar la integridad y el formato de la información** que fluye desde el Frontend hacia el Microservicio de IA.

---

## 🛠️ Contribuciones Técnicas Específicas

### 🛡️ Arquitectura de Validación
Implementé capas de validación técnica para garantizar que los datos de entrada (aerolínea, origen, destino, distancia) cumplieran estrictamente con los formatos requeridos. 
* **Impacto:** Esto evitó errores de ejecución en el modelo de Machine Learning y aseguró la estabilidad del sistema integrador.

### 📜 Documentación Técnica (Swagger/OpenAPI)
* **Acción:** Documenté cada endpoint utilizando **Swagger**, definiendo esquemas de petición, códigos de estado HTTP y parámetros de consulta.
* **Resultado:** Facilitó que el equipo de Frontend y los encargados de la conexión con FastAPI tuvieran una referencia clara y funcional, reduciendo tiempos de integración.
